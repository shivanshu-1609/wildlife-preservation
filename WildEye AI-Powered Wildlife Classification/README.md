# Wildlife Preservation - Image Classification Project

This project uses deep learning to classify different wildlife species from images.  
It aims to support wildlife preservation by helping in automated animal identification.

## 🔧 Technologies Used
- Python
- TensorFlow / Keras
- NumPy, Pandas, Matplotlib

## 📂 Project Structure
- `src/` - All source code (model, training, prediction)
- `data/` - Image datasets
- `notebooks/` - For data exploration
- `saved_models/` - Saved trained models
